# Suryansh Tiwari | Portfolio

Personal portfolio built with plain HTML, CSS and JavaScript. Blue and black theme, fully responsive.

Live site: https://SuryanshEng.github.io

## Files
- `index.html` page content
- `style.css` styling (theme colours are variables at the top)
- `script.js` menu, typing line, certificate filter and viewer, contact form
- `assets/certificates/` certificate images
